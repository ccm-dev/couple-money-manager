Backup

Every change is auto-backed up on this device (latest 20 snapshots kept) — transactions, accounts, people, categories, recurring series and all settings. Restore any point in time, or download one JSON file and drop it in your Google Drive / OneDrive.
The backup file carries everything in a single JSON. Put it in a Drive-synced folder or upload it on drive.google.com — restore it later via Import files (merged) or Replace all.

Cloud Storage

Keep your data file inside your Google Drive or OneDrive folder — this app reads & writes it automatically on Chrome / Android, or use Import & Export on iPhone.
Pick one or several files — everything is added to your current data, nothing is overwritten, and identical transactions are skipped automatically. Migrating from Excel? Grab the template below — it has the exact columns, sample rows and a How-to-fill sheet. To start over from a file instead, use Replace below.
How to store data in Google Drive / OneDrive
  1. Android + Chrome: tap “Link cloud file”, then pick your Google Drive or OneDrive folder (install the Drive / OneDrive app first). Every change is written back to that file automatically — the Drive / OneDrive app then syncs it to the cloud.
  2. iPhone: Safari can’t write files directly. After editing, open Settings → Backup → “Download backup file” → Share → “Save to Files” → choose your OneDrive / Google Drive folder. Next time, open this app and tap “Import files” (you can select several at once) — Drive and OneDrive appear inside the iOS Files picker.
  3. Family sharing: put the JSON file in a shared Drive / OneDrive folder — everyone links the same file and shares one dataset. Last save wins, so sync after editing.
  4. No hosting, fully offline: download this HTML file once to your phone and open it in Chrome (Android) or the free “Documents” app (iPhone). Everything also auto-saves in the browser as a local backup.

Money Manager Mobile v1.20 — single-file app, works offline, no hosting required. Income / Expense / Transfer transactions, custom account types with asset / liability kinds, credit-card statement cycle — a liability-only setting (per-account override or per-type default) — with a billing-period breakdown (tap a period to see its transactions + closing balance), recurring transactions (daily / weekly / monthly / yearly, every N periods — auto-added up to today), balance = start + income − expenses + transfer in − transfer out, transactions listed latest date first with a category filter on the Transactions page, cumulative balance at every level of the account drill (month end → day end → after each transaction), collapsible account summary (people → account types → accounts), footer navigation stays visible on every screen, split expenses — payer fronts all (the full amount leaves the payer's account; every other person's share is credited to a receivable asset account like “HKO owes WHY” under the payer — settle it with a Transfer from that account) — and deleting a split bill removes every related transaction it created (with undo), account & person drill-down (also combined), tap-to-edit in every drill, batch select · edit · delete with undo, full-screen report screens, per-person CSV, display themes. Compatible with the desktop dashboard format (Date, Income/Expense, Category, Subcategory, Account, Person, Note, Amount, Split, To Account). Excel upload template: download a ready-made XLSX with the exact columns, sample rows and a How-to-fill sheet for data migration. Multi-file import: pick several JSON / CSV / XLSX files at once — they are merged into your existing data (nothing is overwritten, identical transactions are skipped), and Replace all with a file restores from a snapshot when you want a clean start. Clear data lets you choose exactly which lists to wipe — or wipe everything. Auto-backup: every change is snapshotted on-device (latest 20, restore any point from Backup history) and one tap downloads a single JSON backup file that can be dropped into Google Drive / OneDrive and re-imported any time. v1.16: every delete — transactions, accounts, people, categories, sub-categories, account types, recurring series, clear-data — shows an Undo toast right after; all pictorial icons are replaced with a consistent line-icon set; and every list & dropdown is sorted alphabetically (icons before the wording are ignored). v1.17: the Add/Edit form no longer asks “Paid by” — the Owner of the selected account is shown instead and stamped on the transaction (transfers carry the From-account owner). A transfer between two different owners offers an Amount owed tick box: on top of the two transfer legs it books a third entry into a jointly-owned debt ledger like “HKO owes WHY” (+ when the receiver borrows, − when they pay it back), so everything one side owes the other lives in one shared account — settle it with a Transfer out of that ledger. v1.18: a tighter Add/Edit form — Repeat now sits beside Date, and the Owner display sits beside the Account field (beside From account on transfers); jointly-owned groups like “HKO & WHY” show a couple icon instead of a dash. v1.19: the Each-pays-own split mode is removed — splitting is always payer fronts all; and joint owner groups like “Husband & Me” now show the net debt between the two people (ledgers of 50 and 100 read RM 50 net with who-owes-who, not the gross 150). v1.20: transfers show a separate owner box for each side — From owner beside From account, To owner beside To account — and you can swipe left / right anywhere on the page to jump between Overview, Transactions, Accounts and Settings.
